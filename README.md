# AutoDNS

Программа для Windows, которая ставит DNS выбранного поставщика и поддерживает его. Работает из области уведомлений: назначает адреса на сетевые адаптеры, включает DNS over HTTPS и те же шаблоны DoH для Chrome и Edge.

Текущая версия: **2.3**.

## Установка

Нужны Windows 10 или 11, 64-bit, и права администратора.

Скачайте установщик со [страницы релизов](https://github.com/korshikovnk/AutoDNS/releases/latest) и запустите `AutoDNS-Setup-2.3.exe`. Установщик копирует программу в `Program Files\AutoDNS`, создаёт ярлык в меню «Пуск» и задачу планировщика, которая запускает AutoDNS при входе в Windows.

## Меню в трее

| Пункт | Что делает |
| --- | --- |
| Обновить | Заново получает адреса поставщика, применяет их и сверяет версию с релизами на GitHub |
| Авто | Возвращает DNS адаптера на DHCP |
| Поставщики | dns.malw.link, Comss.one, Xbox DNS, GeoHide, Astracat. Галочка — выбранный, значок рядом — открываются ли через него ChatGPT, Gemini, Claude, Grok и Cursor |
| Автозапуск | Запуск при входе в Windows. Включён по умолчанию |
| Автообновление | Выкл., каждый час, день, неделю или месяц. По умолчанию — каждый день |
| Закрыть программу | Завершает программу и оставляет текущие настройки DNS |
| Удалить программу | Возвращает автоматический DNS, снимает задачи и удаляет программу |

Меню остаётся открытым после выбора пункта и закрывается щелчком мимо него или клавишей Esc. «Закрыть программу» и «Удалить программу» закрывают его сразу.

Над временем показана версия. Если на GitHub есть более новый релиз, строка меняется на «Доступно обновление: 2.3->2.4» и открывает страницу релизов. Подменю «Автообновление» открывается влево.

Зелёный значок — через этот DNS открываются все пять сайтов: ChatGPT, Gemini, Claude, Grok и Cursor. Жёлтый — не открылся хотя бы один. Красный — не открылся ни один. Имена есть в подсказке. Буква D в трее красится так же для выбранного поставщика. В режиме «Авто» она белая.

По умолчанию выбран dns.malw.link.

Настройки хранятся в `%ProgramData%\AutoDNS\settings.json`.

## Что меняется в системе

- На физических адаптерах с IPv4 прописываются DNS-адреса поставщика. Виртуальные, loopback, Bluetooth и туннельные адаптеры не трогаются.
- Для этих адресов регистрируется DoH.
- В политиках Chrome и Edge включается режим DoH `secure` с шаблоном выбранного поставщика.
- После применения сбрасывается кэш DNS.

Режим «Авто» и удаление возвращают DNS адаптеров на DHCP и снимают политики браузеров.

## Сборка

Нужен [.NET SDK 8](https://dotnet.microsoft.com/download/dotnet/8.0). Для установщика — [Inno Setup 6 или 7](https://jrsoftware.org/isinfo.php); без него скрипт оставляет только `publish\AutoDNS.exe`.

```powershell
dotnet test AutoDNS.sln
.\scripts\publish.ps1
```

Установщик появляется в `dist\AutoDNS-Setup.exe`. Сборка самодостаточная, отдельный runtime .NET на целевой машине не нужен.
