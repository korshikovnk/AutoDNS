# AutoDNS

Программа для Windows, которая ставит DNS выбранного поставщика и поддерживает его. Работает из области уведомлений: назначает адреса на сетевые адаптеры, включает DNS over HTTPS и те же шаблоны DoH для Chrome и Edge.

Текущая версия: **2.1.8**.

## Установка

Нужны Windows 10 или 11, 64-bit, и права администратора.

Скачайте установщик со [страницы релизов](https://github.com/korshikovnk/AutoDNS/releases/latest) и запустите `AutoDNS-Setup-2.1.8.exe`. Установщик копирует программу в `Program Files\AutoDNS`, создаёт ярлык в меню «Пуск» и задачу планировщика, которая запускает AutoDNS при входе в Windows.

## Меню в трее

| Пункт | Что делает |
| --- | --- |
| Обновить DNS | Заново получает адреса поставщика и применяет их |
| Поставщик DNS | Выбор поставщика. «Авто» возвращает DNS адаптера на DHCP |
| Автообновление | Выкл., каждый час, день, неделю или месяц. По умолчанию — каждый день |
| Автозапуск | Запуск при входе в Windows. Включён по умолчанию |
| Закрыть | Завершает программу и оставляет текущие настройки DNS |
| Удалить | Возвращает автоматический DNS, снимает задачи и удаляет программу |

У выбранного поставщика в подменю стоит галочка. Зелёная — DNS отвечает, красная — проверка не прошла. Проверяется ответ сервера, а не доступность отдельных сайтов.

Поставщики: dns.malw.link, Xbox DNS, GeoHide, Astracat. По умолчанию выбран dns.malw.link.

Настройки хранятся в `%ProgramData%\AutoDNS\settings.json`.

## Что меняется в системе

- На физических адаптерах с IPv4 прописываются DNS-адреса поставщика. Виртуальные, loopback, Bluetooth и туннельные адаптеры не трогаются.
- Для этих адресов регистрируется DoH.
- В политиках Chrome и Edge включается режим DoH `secure` с шаблоном выбранного поставщика.
- После применения сбрасывается кэш DNS.

Режим «Авто» и удаление возвращают DNS адаптеров на DHCP и снимают политики браузеров.

## Сборка

Нужен [.NET SDK 8](https://dotnet.microsoft.com/download/dotnet/8.0). Для установщика — [Inno Setup 6 или 7](https://jrsoftware.org/isinfo.php); без него скрипт оставляет только `publish\AutoDNS.exe`.

```powershell
dotnet test AutoDNS.sln
.\scripts\publish.ps1
```

Установщик появляется в `dist\AutoDNS-Setup.exe`. Сборка самодостаточная, отдельный runtime .NET на целевой машине не нужен.
